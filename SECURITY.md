# Security Policy

## Scope

This repository contains Markdown instructions for an Agent Skill. It has no executable code, scripts, or runtime dependencies.

## Reporting

Do not open a public issue for a security problem in the guidance, such as an instruction that could cause an agent to take an unsafe action. Use GitHub's private vulnerability reporting on the Security tab.

Include the affected file, the risky instruction, the scenario, and a suggested fix. Reports are handled on a best-effort basis; no response time is guaranteed.
