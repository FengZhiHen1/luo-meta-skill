# Release Note Review

1. Read the note and the linked issues.
2. Grade every change by impact before checking any wording detail.
3. Report wording problems only after the impact grade is set.
4. Write the summary for the release manager.

Read references/format.md when the note has more than three changes. Read references/review.md before the first review in a session.
